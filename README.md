I'm a B.Tech student focused on systems engineering, infrastructure, automation, networking, and practical software design.

## 🔧 Featured Projects

### [Forsaken-Apex](https://github.com/Codiosityy/Forsaken-Apex) ⭐ — *DeepTech Grand Finalist*

Production-ready semiconductor defect detection pipeline using MobileNetV2 + SE Attention. Trained on 9,000+ images with synthetic data augmentation via Stable Diffusion for class balancing. Achieved 86.6% accuracy on INT8 edge-deployed model for NXP hardware.

**Stack:** TensorFlow, Keras, Computer Vision, Edge AI, Synthetic Data Generation

---

### [DualZen](https://github.com/Codiosityy/DualZen)

Cross-platform browser workspace synchronization system using Python native messaging + browser extension. Syncs pinned tabs, tab groups, and workspace organization via Google Drive across dual-boot machines. Implemented full backup/restore pipeline with session file encoding.

**Stack:** Python, JavaScript, Browser Extensions, Google Drive API, Native Messaging

---

### Local LLM Infrastructure

Offline AI assistant pipeline using llama.cpp and Ollama with tool-calling workflows for task automation. Built local execution environment with GPU acceleration and privacy-first architecture — no API calls leave the machine.

**Stack:** llama.cpp, Ollama, LangChain, Python, Local AI

---

### Self-Hosted Infrastructure

Personal cloud and media infrastructure using Nextcloud deployed via Docker with remote access configured through DDNS and port forwarding. Includes media server, notes synchronization, and cross-device file sync.

**Stack:** Docker, Nextcloud, Linux, DDNS, Reverse Proxy, Self-Hosting

---

### [VisualizeSim](https://github.com/Codiosityy/VisualizeSim) — *1st Place Hackathon Winner*

Simulation visualization system for interpreting complex datasets. Designed interactive UI for extracting meaningful insights from simulation outputs. Won 1st place at Mirabilis Design VisualSim Hackathon.

**Stack:** Python, Data Visualization, UI/UX
